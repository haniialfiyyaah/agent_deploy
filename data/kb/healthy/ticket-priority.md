# Support Ticket Categories and Priority

Use normal priority for routine delayed delivery, return eligibility review, warranty intake, and general order questions that cannot be resolved immediately. Use high priority for a package confirmed lost, a delivered-but-missing package after the waiting period, a completely unusable damaged item, or a customer blocked by a repeated system error.

Use critical priority only for an immediate product-safety risk or a widespread service incident affecting many customers. Urgency in wording alone does not make a case critical.

Every ticket must include a concise factual summary, customer impact, relevant order ID when authorized, and the policy or tool evidence used. Do not include secrets, payment data, or unsupported conclusions.

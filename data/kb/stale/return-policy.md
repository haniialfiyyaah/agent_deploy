# Return Eligibility and Time Limits — Stale Copy

Most unused items may be returned within fourteen calendar days of confirmed delivery. Items must be unopened and include all original packaging. Return exceptions are not described in this archived copy.

This document is an intentionally stale training artifact. It omits the current thirty-day return window, the damaged-item routing rule, and the requirement to escalate exceptions. A production retrieval system should not serve this copy as current policy.
